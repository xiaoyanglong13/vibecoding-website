Module 5 · About 75 minutes + optional extension

Scaling up

In Module 4, you learned to work with an AI agent to build and verify a solution. Now that you have something that works, how do you keep improving it safely and make it useful to other people?

From a working prototype to a usable solution

Imagine you have built a dashboard for a small business. It works on your computer, but you want to keep improving it and let someone else use it. Three practical questions come next:

  1. What if a change breaks something? You need a way to track changes and recover a working version.
  2. How can someone else use it? You need to put the dashboard somewhere others can access it.
  3. What if the dashboard could do more? In some projects, you may want to add AI-powered features for the end user.

These questions form the core path through this module:

Build and verify a prototype (Module 4)
  ↓
Track changes and save working versions (Git)
  ↓
Share the application with others (deployment)
  ↓
Optional advanced capability: add AI features (APIs)

Not every project needs AI built into it. A dashboard, calculator, or interactive report can be useful on its own. And even if AI helps you build an application, that does not mean the application itself uses AI. The third lesson explains when and how to make that choice.

What you'll be able to do

By the end of the core lessons, you should be able to use Git and GitHub to track changes and recover earlier versions; explain how to deploy a project so others can use it; and understand how an application can use an AI model through an API, including the basic implications for cost, privacy, and security.

In this module

Page 1 · 25 minutes

1. Keep track of changes →

Your agent can edit many files quickly, and not every change will work. Learn how Git helps you inspect changes, save checkpoints, and recover an earlier working version. See how GitHub can help you store and share your project history.
Page 2 · Coming soon

2. Share and deploy what you build

A working project on your computer is not yet something others can use. Learn the basics of hosting and deployment, how to publish a simple application, and what to check before sharing it with real users.

Page 3 · Coming soon · Advanced topic

3. Put AI inside your solution

So far, you have used AI to build applications. Here you will learn how an application can use AI—for example, to summarize customer feedback or answer questions. Explore APIs, model calls, API keys, usage costs, and safeguards.

Page 4 · Optional extension · 35 minutes

4. Extend your agent: Skills and MCP →

Package recurring workflows as reusable skills, and use MCP to connect your agent to external tools and information. Learn how these differ from the project instructions you used in Module 4.

Other extensions, such as subagents and agent teams, can help divide complex work among specialized agents. They are useful to explore later, but not necessary for most of the projects in this course.
