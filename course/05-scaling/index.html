Module 5 · 75 minutes core + optional extension

Scaling up

So far, you have focused on getting an agent to help you build something that works. The next step is turning that prototype into a solution that is safer to change, easier to share, and useful to other people.

From prototype to real solution

A project that works once on your laptop is a good start. But real business solutions usually need more. You need to keep track of changes, preserve workflows you will use again, connect AI directly to the product when it adds value, and make the finished solution accessible to other people.

Optional: Extend your agent with skills and MCP

This module introduces those next steps. You do not need to become a professional software engineer. The goal is to understand the basic ideas well enough to build solutions that are safer to change and easier for other people to use.

What you'll be able to do

By the end of this module, you should be able to use Git and GitHub to keep a history of your work, use skills to reuse procedures and MCP to connect your agent to external tools and data, understand how an app can call an AI model through an API, and deploy a simple solution so someone else can actually use it.

In this module

Page 1 · 25 minutes

1. Keep track of changes →

Learn the basic idea behind version control and use Git and GitHub to save checkpoints, inspect what changed, recover an earlier version, and collaborate without passing around files named final_v7_really-final.xlsx.

Page 2 · Coming soon · Core

2. Share and deploy what you build

Move from “it works on my computer” to something another person can actually use. Learn the basic ideas behind hosting, deployment, environment variables, secrets, updates, and maintaining a solution after it goes live.

Page 3 · Coming soon · Advanced core topic

3. Put AI inside your solution

So far, you have mostly used AI to build things. Now explore when AI should become part of the thing you build—for example, a website that sends a user's input to an LLM. Learn about APIs, model calls, structured outputs, API keys, costs, and safeguards.

Page 4 · Optional extension · 35 minutes

4. Extend your agent: Skills and MCP →

Go further with the agent that helps you build. Package recurring procedures into reusable skills, and use MCP to connect the agent to external tools and data. Useful for more complex workflows, but not required to build and deploy an application.

What about subagents and agent teams?

Beyond the optional skills and MCP page, you can also experiment with subagents that take on specialized parts of a larger task, or agent teams that coordinate several agents at once. These are useful extensions, but they are not necessary for most of the business projects in this course.
