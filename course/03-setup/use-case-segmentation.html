Use case: From customer CSV to dashboard

Can you turn a messy customer spreadsheet into a useful marketing dashboard without writing code yourself? Give Claude Code a business goal, then explore what it builds.

Difficulty · Beginner Uses: Claude Code in VS Code Output: Interactive HTML dashboard

1. The business challenge

You're a growth marketer at a B2B SaaS company. The head of marketing wants to replace a generic campaign with more targeted outreach. You have a customer dataset, but no existing customer segments.

For tomorrow's planning meeting, she wants you to identify three actionable customer segments and recommend two campaigns to prioritize. For each segment, she wants to understand:

  • Who belongs in it and how many customers it includes
  • What makes those customers distinct and why the segment matters
  • What marketing message might resonate with them
  • Which outreach channel you recommend, and why

She also wants something more engaging than a spreadsheet: a clear, visually appealing HTML dashboard that shows the data, the segments, and your recommendations. It should open directly in a web browser.

2. Your starting data

Download the sample dataset (800 rows) and save it as customers.csv in a new folder named customer-segmentation.

The dataset contains the following fields:

customer_id, company_name, industry, employee_count,
plan_tier, mrr_usd, signup_date, last_login_days_ago,
features_used_30d, support_tickets_90d, csm_assigned

As in real business data, not everything is perfectly clean. For example, industry labels vary, plan names are inconsistently capitalized, and some employee counts are missing. You don't need to clean the file manually.

3. Build it with Claude Code

  1. Open your folder in VS Code. Make sure customers.csv is inside, then start Claude Code in that folder.
  2. Write your own prompt. Explain the business challenge, what data Claude Code can use, and what you want it to produce. You decide how much detail to provide. There is no model prompt to copy.
  3. Let the agent work. Claude Code may inspect the CSV, write and run analysis code, and create output files. Review any actions or permissions it asks you to approve.
  4. Open the result. Find the generated dashboard.html in your project folder and open it in your browser. If the agent chose a different filename, ask it to save the dashboard as dashboard.html.

Try starting with a single prompt that describes the whole task. You can always follow up if you want to clarify or change something.

4. Explore your dashboard

Your dashboard should help a nontechnical marketing director understand the analysis and decide what to do next. Explore what Claude Code built rather than assuming it matches what you pictured.

  • Data: Can you see useful patterns in the customer base, including the ones behind the final segment names?
  • Segments: Are the three segments clearly described, with counts and meaningful comparisons?
  • Recommendations: Does the dashboard explain the two campaigns it would prioritize and the rationale for each?
  • Presentation: Are the charts readable? Can a manager navigate the dashboard without knowing the code?

There is no single correct dashboard design. Different prompts may lead to different charts, segmentation logic, layouts, and recommendations.

5. Share, compare, and improve

Pair up with a classmate. Share your dashboards and explain the customer segments you identified, the two campaigns you recommend, and why.

Discuss together:

  • Similarities: What do your dashboards and recommendations have in common?
  • Differences: How do your segment definitions, charts, campaign priorities, or recommendations differ?
  • Improvements: What did you learn from your classmate's approach? What would you change about your own dashboard or recommendations?

Use what you learned to ask Claude Code to revise your dashboard. Open the updated HTML file in your browser and review the changes.

6. Reflect

Before moving on, think about these questions:

  • What did your first prompt accomplish? What, if anything, required a follow-up?
  • What files did Claude Code create or modify in your local project folder?
  • Which decisions did you leave to AI, and which did you make yourself?
  • How would you check whether its segment definitions and marketing recommendations actually make business sense?

Takeaway

You didn't need to write the data-cleaning script, the charts, or the HTML by hand. You described a business objective, and an AI coding agent worked with local files to produce a usable artifact that you could open and revise. In later modules, we'll look more closely at how to verify the analysis and guide larger projects.
