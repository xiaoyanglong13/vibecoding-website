Tool overview

Claude Code works best with a few supporting tools already in place. This page is the checklist and the why; the next two pages walk through actually installing everything, step by step, on Mac or Windows.

What you'll be able to do

Know what's being installed and why, before jumping into the Mac or Windows walkthrough.

The full install list

Eight tools, installed once, so nothing shows up as a surprise mid-course install later.

Tool What it's for Mac Windows
Xcode Command Line Tools Foundation dependency Homebrew needs to run xcode-select --install Not needed
Homebrew Package manager used to install everything else below, on a Mac /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)" Not needed
Node.js + npm Runs Claude Code, which is distributed as an npm package brew install node Official installer
Git Tracks changes an agent makes to your files, so you can roll one back brew install git Official installer
Miniconda Gives agent-written Python scripts a consistent environment to run in brew install --cask miniconda Official installer
Pandoc Converts agent-drafted documents into Word, PDF, and other formats brew install pandoc Official installer
VS Code Editor you'll use to browse and read an agent's files brew install --cask visual-studio-code Official installer
Claude Code The agent itself npm install -g @anthropic-ai/claude-code Same command

What each tool does, and why it's here now

Xcode Command Line Tools (Mac only)

A small set of developer utilities Apple ships separately from the full Xcode app. Homebrew, the next tool on this list, won't run without it. Windows has no equivalent.

Homebrew (Mac only)

The standard package manager for Mac — a single command-line tool for installing, updating, and removing other software. Once it's in place, most of the rest of this list becomes one short command each. Windows has no equivalent; each tool there gets its own installer instead.

Node.js and npm

Node.js is a JavaScript runtime, and npm is the package manager that ships with it. Claude Code is distributed as an npm package, so installing Node.js is a required step no matter what else ends up on your laptop.

Git

Git tracks changes to files over time. You won't use it directly until Module 4, when reviewing — and sometimes rolling back — an agent's edits becomes part of the workflow. It's easiest to install once now rather than mid-course.

Miniconda

Later in the course, you'll ask an agent to write and run a Python script against real files — for example, updating a financial model from a trial balance. Miniconda installs Python along with conda, a tool for keeping each project's Python setup separate and consistent. Installing it now means every agent you run has the same Python environment to work with.

Pandoc

Pandoc converts documents between formats — for example, turning a plain-text draft into a Word document formatted to match one you already have. One of this course's use cases asks an agent to produce a recap document that matches an existing reference document's formatting exactly; Pandoc is what makes that possible.

VS Code

A code and text editor. Starting on page 5 of this module, you'll use it to open the folders an agent is working in, read the files it produces, and run Claude Code from its built-in terminal.

Claude Code

The agent itself.

Key takeaway Claude Code's own install command is identical on Mac and Windows — unlike most of the tools above it, there's no OS-specific branching.
