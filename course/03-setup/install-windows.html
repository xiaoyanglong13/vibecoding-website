Install on Windows

Every command on this page runs in PowerShell. Unlike Mac, there's no single package manager doing the work — each tool gets its own installer. Follow it top to bottom. (On Mac? Skip to the macOS walkthrough instead.)

What you'll be able to do

Have all eight tools installed and configured on Windows, confirmed with a full version-check.

Find PowerShell

Open the Start menu, type PowerShell, and press Enter. (On Windows 11, this opens inside Windows Terminal — a modern wrapper around the same thing.) The prompt looks like PS C:\Users\yourname> — that's where you type.

Enter runs whatever you've typed, the up arrow recalls your last command, and right-click pastes from the clipboard.

Allow scripts to run

Windows blocks unsigned scripts by default, which trips up several installers below. Loosen that, for your account only:

Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

RemoteSigned lets local scripts run freely while still requiring downloaded scripts to be signed; -Scope CurrentUser applies only to your account, so it doesn't need administrator rights. Verify:

Get-ExecutionPolicy

It should print RemoteSigned.

Git

Download the installer from git-scm.com/downloads/win and run it. Accept the defaults, with one exception: on the PATH screen, select "Git from the command line and also from 3rd-party software." Without that, PowerShell won't find git.

Close PowerShell, reopen it, and verify:

git --version

Then tell Git who you are:

git config --global user.name "Your Name"
git config --global user.email "your@email.com"

Verify:

git config --global --list

Node.js

Download the LTS installer from nodejs.org/en/download. Keep the default options, and make sure "Add to PATH" is checked. In a new PowerShell window, verify:

node --version
npm --version

Claude Code

Install it with:

npm install -g @anthropic-ai/claude-code
Key takeaway This install command is identical on Mac and Windows — unlike most of the tools above it, there's no OS-specific branching here.

Verify:

claude --version

VS Code

Download the installer from code.visualstudio.com. Keep the defaults, and make sure "Add to PATH" is checked. Verify:

code --version

Miniconda

Download the Windows installer from anaconda.com/miniconda. On the Advanced Options screen, leave "Add Miniconda3 to PATH" unchecked — it's marked "not recommended" because it can conflict with other Python tools. Instead, initialize it after installing, from a new PowerShell window:

conda init powershell

Close and reopen PowerShell. Your prompt should now start with (base). Verify:

conda --version
python --version

If conda still isn't recognized, open "Anaconda Prompt (miniconda3)" from the Start menu instead of plain PowerShell.

Pandoc

Download the .msi installer from pandoc.org/installing.html and run it — Pandoc adds itself to PATH automatically. In a new PowerShell window, verify:

pandoc --version

Confirm everything

In a fresh PowerShell window, run all of these. Each should print a version number — never "command not found":

git --version
node --version
npm --version
claude --version
code --version
conda --version
python --version
pandoc --version
If something goes wrong "Command not recognized" right after installing something — close and reopen PowerShell. Installers update PATH, but a window that was already open won't see the change. If it still fails, check whether that tool's "Add to PATH" option was actually selected during setup.

A script-execution error — re-run the Set-ExecutionPolicy command above; it may not have taken effect.

An npm install -g times out — this is usually a network hiccup. Wait and try again.
