Appendix: OpenCode

Claude Code is this course's tool of choice, but it isn't the only agent that runs in a terminal. OpenCode is a free, open-source alternative worth knowing about. This page is optional — read it if you're curious how another tool compares, or skip ahead to Module 4.

What you'll be able to do

Install OpenCode, launch it from VS Code's integrated terminal, connect it to a model provider, and know how it differs from Claude Code.

Why this is an appendix, not a fork in the road

OpenCode and Claude Code solve the same basic problem — an AI agent that reads and edits files from a terminal — but they're built with different priorities. OpenCode is provider-agnostic: it can connect to Anthropic's models, but also OpenAI's, Google's, or a dozen others, which makes it a low-cost way to try several providers before committing to one. Claude Code is built by Anthropic specifically for Claude, and trades that flexibility for deeper project features — Skills, sub-agents, and hooks among them — that this course leans on from Module 4 onward.

Aspect OpenCode Claude Code
Model support Many providers — Anthropic, OpenAI, Google, and others Anthropic's models only, tightly integrated
Getting started Lower — pick a provider and go One account, one login, more built-in structure
Project features File, command, and web access Adds Skills, sub-agents, hooks, and other collaboration tools

For this course, stick with Claude Code — the rest of the modules are written around it, and switching mid-course adds friction for no real benefit. Treat OpenCode as something to know exists, and maybe revisit later if you want to compare providers or shop around on price.

Step 1: Install OpenCode

You already have Node.js installed from earlier in this module, so either command below will work regardless of OS. Mac users can also use Homebrew.

macOS (Homebrew):

brew install anomalyco/tap/opencode

macOS or Windows (npm):

npm install -g opencode-ai

Verify:

opencode --version

Step 2: Launch it from VS Code

Open the integrated terminal the same way you did in the previous page, then run:

opencode
Terminal — opencode
> opencode

  OpenCode
  Run /connect to add a model provider.

  Build mode                                          >

This opens a text-based interface, not a browser window — the conversation runs in the same pane, with an input box at the bottom.

Step 3: Connect a model provider

Unlike Claude Code, OpenCode doesn't come wired to one company. The first time you run it, you'll need to tell it which provider to talk to:

/connect

You'll be given a choice. Two reasonable options:

  • OpenCode Zen — a curated list of models OpenCode recommends for beginners. Sign in at opencode.ai/auth, add billing, and paste the API key it gives you back into the terminal when prompted.
  • Anthropic — reuse the same API key you may have created in Option B of the login page, if you'd rather talk to Claude specifically.

Step 4: Try a prompt

Same smoke test as the previous page — a prompt that only works if the agent can actually see your files:

What files are in this folder?

If it lists what's actually there, OpenCode is installed, connected, and reading real files — the same bar Claude Code had to clear.

Two modes: Build and Plan

Press Tab to switch between them:

Mode What it can do
Build (default) Reads, writes, and edits files, and runs commands
Plan Read-only — analyzes and proposes, but changes nothing
Tip On an unfamiliar project, switch to Plan mode first and let the agent read the code and propose an approach. Once you've looked over the plan, switch back to Build mode to actually let it make the changes. This costs a few extra seconds and saves you from an agent confidently editing the wrong file.

Useful commands

Type / in the input box to see the full list with autocomplete. The ones you'll reach for most:

Command What it does
/connect Add or switch a model provider
/models View and switch which model you're talking to
/new Start a fresh conversation, no prior context
/compact Compress a long conversation once it's eating too many tokens
/sessions Browse past conversations
/undo / /redo Revert or restore file changes (needs Git)
/init Generate a project instructions file, similar to Claude Code's CLAUDE.md
/help Show the full command list
/exit Quit OpenCode
Good to know Two more shortcuts worth remembering: type @ followed by a filename to pull that file's contents into your prompt (for example, @report.md summarize this), and prefix a line with ! to run it as a shell command and feed the output back into the conversation (for example, !git log --oneline -5).

Which one should you use?

For this course, Claude Code — everything from Module 4 forward assumes it. OpenCode is worth having installed if you want to compare how a prompt performs across providers, or if cost pushes you toward a cheaper model later on. Knowing both means you're never locked into one vendor's pricing or roadmap.
