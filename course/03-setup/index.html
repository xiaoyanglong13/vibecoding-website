Module 3 · ~90 minutes

Setting up your workspace

Install every tool this course needs, log in, and get Claude Code running from inside VS Code. A longer module than most — it's a one-time setup, not a concept to learn.

What you'll be able to do

Have a working Claude Code installation on your laptop, logged in and running from VS Code, with your first "hello world" agent run completed.

Sub-pages

  • Tool overview. The checklist and the why: the eight tools this course needs, and what each one is for.
  • Install on macOS. Terminal, Homebrew, and one command for most of the list.
  • Install on Windows. PowerShell and an installer for each tool.
  • Log in to Claude Code. Claude account login, or an API key for usage-based billing.
  • Using Claude Code in VS Code. Getting oriented, opening a project folder, and running Claude Code from the built-in terminal.
  • Your first agent run. A tiny task — "summarize the README in this folder" — to confirm everything works end to end.
  • Appendix: OpenCode. The open-source alternative, when you might prefer it, and how it differs.
