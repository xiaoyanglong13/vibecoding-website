Module 4 · 175 minutes

The vibecoding workflow

The repeatable loop that separates people who get real work done from people who fight their AI tools all day.

What you'll be able to do

Take a fresh project from "blank folder" to "working artifact" using a consistent workflow you can apply to any task: plan first, set up your information environment, specify the task at the right level of detail, verify the result before you trust it, and give the agent memory across sessions — then see the whole loop applied twice, in a people case and a finance case.
