Case study: event recap generator

A fast, low-stakes task where all four of this module's skills show up in one sitting. The full build is already written up in the use case library — this page just points you to it.

Where each skill shows up

As you read the case, watch for these four moments — each one is the case's version of a page you just read:

  • Plan before you execute. Rather than guessing at a format, the plan is a plan for how to learn it: interview the user one question at a time before writing anything.
  • Information environment. An inputs/references/outputs folder, where the reference document — not a written description — is the ground truth for format.
  • Specifying the task. The CLAUDE.md gets written together from the interview answers, stating mandatory sections and format rules rather than over- or under-specifying.
  • Memory across sessions. The folder itself becomes memory: next semester's run starts from a references/ folder and a CLAUDE.md that already know what a good recap looks like.
