Module 2 · 45 minutes

From prompt to agent

What changes when the AI can read your files, run code, and act in loops — and why that changes what's possible.

What you'll be able to do

Explain what an "agent" actually is, recognize when a task needs one versus a regular chatbot, and walk through one fully-worked end-to-end example before installing anything.

How this module is structured

Three sub-pages, in order:

15 min · Concepts

1. The agent mental model

The "junior analyst with desktop access" analogy. What's new compared to plain chat: files, tools, loops.
20 min · Walkthrough

2. A fully-worked example

Trace an agent taking a vague request and producing a finished artifact, end to end.
10 min · Rubric

3. When an agent helps and when it doesn't

A decision rubric: task shape, data location, repeatability.
