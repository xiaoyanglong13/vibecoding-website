Syllabus

The course

Seven modules, roughly ten hours of work end-to-end. Designed to be done in order, but built so you can drop in laterally via the reference and case sections.

Prerequisites

A laptop you can install software on, basic comfort working with files and spreadsheets, and willingness to spend about 90 minutes setting up your workspace in Module 3. No programming experience is required.

Modules

#ModuleTime

1 Talking to AI
Prompting fundamentals. The difference between chatting and building.		 45 min

4 The vibecoding workflow

6 Limits, risks, and responsibility
Protecting information, controlling agent actions, real costs, and when not to vibecode.		 90 min
7 Business use cases
Real cases by business function.		 varies
If you only have one hour

Do Module 0 and the first sub-page of Module 1. You won't be able to build anything yet, but you'll know whether the rest of the course is worth your time.
